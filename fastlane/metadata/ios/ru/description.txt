Chord Expert объединяет аккорды, теорию музыки, тюнер и метроном для гитары, укулеле, мандолины, бас-гитары и банджо в одном приложении, которое работает полностью офлайн, без рекламы, без аккаунта и без слежки.

ПОЧЕМУ CHORD EXPERT
• Рассчитано по теории музыки, а не взято из базы — каждый аккорд строится из своих нот, а аппликатуры вычисляются для вашего инструмента, строя и каподастра, поэтому ни один аккорд и ни одна позиция не пропущены
• Плавные последовательности — аппликатуры подбираются для всей последовательности, чтобы рука перемещалась как можно меньше
• Работает в обе стороны — отметьте аппликатуру и узнайте название аккорда, введите несколько аккордов и узнайте тональность
• Настоящие звуки инструментов — слушайте каждый аккорд боем или перебором
• Приватность по умолчанию — у приложения вообще нет доступа к интернету

АККОРДЫ
• Диаграммы любого аккорда во всех позициях на грифе
• Оценка сложности и номера пальцев для каждой аппликатуры, можно показывать только простые
• Обращения и аккорды с басом, например C/E или D/F#
• Поиск аккорда по аппликатуре, включая обращения и неполные аккорды
• Избранное для каждого инструмента

ТЕОРИЯ
• Тональности и лады: диатонические трезвучия и септаккорды для мажора, минора, ладов, пентатоники, блюза и других
• Самая вероятная тональность по аккордам песни
• Интерактивный квинтовый круг
• Гаммы и звуки аккорда на грифе, с интервалами или названиями нот
• Самые удобные позиции каподастра для любой тональности

ПОСЛЕДОВАТЕЛЬНОСТИ
• Типичные последовательности для поп, рока, джаза, блюза, классики и фламенко в любой тональности
• Случайные последовательности по законам функциональной гармонии
• Играйте по кругу под метроном

ИНСТРУМЕНТЫ
• Хроматический тюнер с эталонными звуками и калибровкой A4 (430–450 Гц)
• Альтернативные и свои строи: Drop D, DADGAD, Open G, на полтона ниже и ваши собственные
• Метроном с тап-темпом, размерами, делением доли и акцентами

ДЛЯ ВАС
• Режим для левшей
• Тёмная тема и раскладка для планшета
• Английские, немецкие (H) или латинские (До Ре Ми) названия нот
• Более 60 языков
