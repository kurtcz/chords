Chord Expert는 기타, 우쿨렐레, 만돌린, 베이스, 밴조를 위한 코드, 음악 이론, 튜너, 메트로놈을 하나로 담은 앱입니다. 완전히 오프라인으로 작동하며 광고, 계정, 추적이 없습니다.

CHORD EXPERT를 선택하는 이유
• 데이터베이스가 아닌 음악 이론으로 계산 – 모든 코드를 구성음으로 만들고, 악기·튜닝·카포에 맞춰 운지를 계산하므로 빠지는 코드나 포지션이 없습니다
• 매끄러운 코드 진행 – 진행 전체를 고려해 운지를 골라 손 이동을 최소화합니다
• 양방향으로 사용 – 운지를 탭하면 코드 이름을, 코드 몇 개를 입력하면 키를 알려줍니다
• 실제 악기 소리 – 모든 코드를 스트로크나 아르페지오로 들어보세요
• 설계부터 개인정보 보호 – 앱은 인터넷에 전혀 접속하지 않습니다

코드
• 지판 위 모든 포지션에서 어떤 코드든 다이어그램으로
• 모든 운지에 난이도와 손가락 번호 표시, 쉬운 운지만 볼 수도 있음
• C/E, D/F# 같은 전위 코드와 슬래시 코드
• 운지로 코드 찾기, 전위 코드와 불완전한 코드 포함
• 악기별 즐겨찾기

이론
• 키와 스케일: 메이저, 마이너, 선법, 펜타토닉, 블루스 등의 다이어토닉 3화음과 7화음
• 노래의 코드로 가장 가능성 높은 키 찾기
• 인터랙티브 5도권
• 지판 위의 스케일과 코드 톤, 음정 또는 음이름으로 표시
• 키마다 가장 쉬운 카포 위치

코드 진행
• 팝, 록, 재즈, 블루스, 클래식, 플라멩코의 대표 진행을 모든 키로
• 기능 화성에 기반한 랜덤 진행
• 메트로놈에 맞춰 반복 연주

도구
• 기준음과 A4 보정(430–450 Hz)을 갖춘 크로매틱 튜너
• 변칙 및 사용자 튜닝: Drop D, DADGAD, Open G, 반음 내림, 나만의 튜닝
• 탭 템포, 박자, 세분화, 강세를 지원하는 메트로놈

당신을 위해
• 왼손잡이 모드
• 다크 모드와 태블릿 레이아웃
• 영어식, 독일식(H), 라틴식(도레미) 음이름
• 60개 이상의 언어 지원
